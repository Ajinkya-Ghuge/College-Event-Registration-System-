# Ignite SA Events Page

A TypeScript-based event listing page for the Ignite SA student community.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Compile TypeScript:
```bash
npm run build
```

3. Serve the page:
```bash
npm run serve
```

Then open http://localhost:8000 in your browser.

## Development

To watch for changes and auto-compile:
```bash
npm run watch
```

## Structure

- `src/app.ts` - Main TypeScript application logic
- `index.html` - HTML structure
- `styles.css` - Styling
- `dist/` - Compiled JavaScript output

## Features

- Responsive event grid layout
- Dynamic event card generation
- Registration functionality
- Dark theme matching the design
- Hover effects and animations
